# Home

This vault works with or without an agent. There are four doors:

- [[Inbox]] — catch something before it disappears.
- [[Now]] — see the small set that matters today.
- [[Re-entry]] — leave yourself a kind way back in.
- [[System/Configuration Profile|Configuration Profile]] — tell the agent how to help.

> [!tip] The whole loop
> Capture → add enough context → resurface → re-enter. You do not have to organize everything.

> [!info] Your boundaries
> You can pass, pause, change the pace, leave, or return. Nothing in this vault has to be shared with the group.
