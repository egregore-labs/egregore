# Configuration Profile

This note describes how you want an agent to support this vault. It contains preferences, not private note content or diagnostic information. The portable structured copy lives at `.second-brain/configuration-profile.json`.

## Stable core

- Capture goes to [[Inbox]].
- Resurfacing happens in [[Now]].
- A gentle return cue lives in [[Re-entry]].
- The manual path must always remain usable.

## Current preferences

- Ask one concrete question at a time.
- When overwhelm appears, offer a pause, a smaller step, or the manual path.
- Treat everything as private unless I explicitly choose to share it.
- Do not add folders, tags, or recurring maintenance without asking.

## Personalization prompts

- What word feels better than “Inbox”?
- Do I prefer typing, speaking, or alternating?
- What makes a re-entry cue actually useful to me?
- When should the agent stop asking questions?
