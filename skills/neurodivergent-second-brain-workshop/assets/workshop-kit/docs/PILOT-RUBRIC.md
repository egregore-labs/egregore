# Four-person pilot rubric

Use pseudonyms. Record outcomes and system load, not diagnoses or private note content.

## Minimum viability

- [ ] All 4 participants create a usable capture and re-entry loop.
- [ ] All 4 receive and open a verified vault export.
- [ ] At least 3 reopen and use the vault manually without the agent.
- [ ] At least 3 use the system on 3 separate days and return for session 2.
- [ ] All 4 review a portable configuration profile.
- [ ] At least 3 validate their profile with an agent.
- [ ] At least 3 report that the system helped them return, remember, or act.
- [ ] Zero unresolved safety, privacy, forced-disclosure, or credential incidents.

## Decision after the pilot

- **Repeat:** core outcomes met, no unresolved incident, load is sustainable.
- **Revise:** value exists but access, workflow, cost, or teardown needs another thin pilot.
- **Stop:** participants cannot retain value without the temporary agent, risk is unacceptable, or facilitator load is unsustainable.

Do not build self-service provisioning or an admin dashboard until this decision is made from pilot evidence.
