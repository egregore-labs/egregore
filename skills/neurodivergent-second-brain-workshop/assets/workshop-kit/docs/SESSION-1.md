# Session 1 — make a usable loop

Duration: 90 minutes. Outcome: every participant captures something, adds enough context, resurfaces it, leaves a re-entry cue, and can do the same without AI.

## Arrival and control — 0–15

- Show the written agenda and visible timer.
- State the privacy boundary and all exit/re-entry options.
- Let participants choose spoken, written, private, or pass.
- Open Obsidian at [[Home]]; do not open the agent yet.

## Manual core — 15–35

- Put one real fragment in [[Inbox]].
- Optionally add “why it matters” and “next visible step.”
- Move or link only one useful item to [[Now]].
- Write one cue in [[Re-entry]].
- Pause and verify the system works with no AI.

## Agent as configuration partner — 35–65

- Start `./start-workshop.sh`.
- Ask the agent to explain the four-note loop in the participant’s preferred pace.
- Personalize one label, cue, or interaction preference—not the whole vault.
- Ask the agent to show proposed changes before writing.
- Verify the agent updates the configuration profile and preserves the manual path.

## Independent repetition — 65–80

- Participant captures a second item with as much or as little agent support as desired.
- Participant practices stopping and returning from [[Re-entry]].
- Facilitator supports technology, not content interpretation.

## Close — 80–90

- Write a re-entry cue for the days between sessions.
- Invite three days of ordinary use; this is an invitation, not homework compliance.
- Remind participants the isolated workspace persists until session 2 and will be exported before deletion.
